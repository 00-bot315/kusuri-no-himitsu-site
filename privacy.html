ホームプライバシーポリシー利用条件

このページは、運営者本人だけが使う「くすりのひみつ」投稿ツールと、この説明サイトでの情報の扱いを説明します。一般の方のログインやアカウント接続は受け付けません。

現在の Instagram 投稿では、運営者が用意した完成動画・タイトル・説明文、対象アカウントの識別情報、投稿の重複を避けるための記録、Instagram 連携用の認証情報を扱います。完成 MP4 は Instagram に渡すため公開 GitHub リポジトリに置かれ、誰でもアクセスできます。認証情報は非公開の GitHub Actions Secrets で管理し、公開サイトや公開リポジトリには載せません。

YouTube Data API による連携は準備中です。このツールは現時点で YouTube API データを取得・保存していません。YouTube 接続を開始する前に、取得する項目、保存期間、失効・削除時の処理を定めて、このページを更新します。

運営者が用意した動画、説明文および Instagram の投稿記録は、継続する投稿運用に必要な間、運営者が管理します。運営者が削除する場合、該当する管理ファイルを確認して削除します。削除については futari.mirror@gmail.com に連絡できます。公開済みの動画をプラットフォームから消す場合は、Instagram または YouTube でも別途削除が必要です。Google 連携の許可は Google アカウントのセキュリティ設定 から解除できます。許可の解除だけで公開済み動画や管理ファイルが自動で削除されるわけではありません。

このサイト自体は閲覧者の健康情報や診療情報を収集しません。GitHub Pages および GitHub 上の公開動画を閲覧すると、GitHub がアクセスに関する情報を処理する場合があります。GitHub 等の外部サービスのログやバックアップは、それぞれのサービスの管理対象です。GitHub プライバシーステートメントも参照してください。

このツールは YouTube API Services を利用する準備をしています。Google プライバシーポリシーおよびYouTube 利用規約を参照してください。問い合わせ先：futari.mirror@gmail.com。
