ホームプライバシーポリシー利用条件

「くすりのひみつ」の投稿ツールは運営者本人による自身のアカウントへの投稿専用です。一般の方にはログインやアカウント接続を提供しません。YouTube 連携は準備中であり、現時点ではこのツールから YouTube API 投稿を行っていません。

このツールを使って YouTube API Services に接続する利用者は、YouTube 利用規約に拘束されることに同意します。投稿先のプラットフォームの規約も適用されます。

データの扱いと削除についてはプライバシーポリシーを参照してください。問い合わせ先：futari.mirror@gmail.com。
