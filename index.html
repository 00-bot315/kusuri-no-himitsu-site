このツールについて

「くすりのひみつ」は、運営者本人が用意した科学・医療解説の短い動画と説明文を、自身が管理する Instagram と YouTube のチャンネルに投稿するための専用ツールです。一般の方のログインやアカウント接続は受け付けません。

Instagram への投稿連携は使用中です。YouTube Data API を使う動画投稿は準備中で、現時点ではこのツールから動画を投稿していません。接続・投稿先の確認のため YouTube API で情報を読み取り、応答は実行中のメモリ内だけで扱います。投稿成功時は公開動画の URL のみを非公開 GitHub Actions の成果物として保持期間 1 日で保存し、投稿結果の案内に利用します。

扱う内容

運営者が用意した完成動画、タイトル、説明文と Instagram の投稿記録を、投稿と重複防止に用います。Instagram に動画を渡すための完成 MP4 は公開 GitHub リポジトリに置かれ、誰でも閲覧・ダウンロードできます。認証情報は公開せず、専用の非公開 GitHub Actions Secrets で管理します。

このサイトは閲覧者の健康情報や診療情報を収集しません。
